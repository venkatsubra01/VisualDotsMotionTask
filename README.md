# Visual Dots Motion Task

A web-based behavioral experiment for the Random Dots Motion Task, built with Python and JavaScript. Participants view moving dots and respond to the perceived direction using keyboard arrows. Results are visualized and can be downloaded.

---

## Features

- Interactive web interface for running the dots motion task
- Real-time animation of moving dots with adjustable coherence
- Keyboard input for left/right responses
- User name entry modal
- Results page with leaderboard and plots
- Data extraction and conversion from `.rtf` to JSON
- Downloadable results and static plots
